An idea came up: $ARGUMENTS

The current block is **not abandoned**. If the chat is on sonnet — suggest: "The decisions here are costly, better use `/model opus`".

1. If the idea is unclear — one or two clarifying questions.
2. Run the `idea-integrator` agent: the idea, `01-VISION.md`, `03-ROADMAP.md`, `06-IDEAS.md`
   (including "Rejected by the owner"), the headings of `05-DECISIONS.md`.
3. Summary for the owner: does it overlap with the plan or with something already rejected; weight; dependencies; risks;
   **how the percentage will change** ("it was 60%, it will be 52% — the project grew, it did not go backwards").
   A bad idea — say so plainly and why.
4. The owner's decision:
   - **into the roadmap** — a new block with a weight in `03-ROADMAP.md`, recalculate the percentage;
   - **later** — an entry in `06-IDEAS.md`;
   - **no** — a line in "Rejected by the owner" in `06-IDEAS.md` and, if it affects the future, in `05-DECISIONS.md`.
5. Return to the current block.
